123-SMS — Envoi de SMS depuis Odoo

Relances de factures impayées, rappels de rendez-vous, alertes, notifications d'expédition : envoyez des SMS depuis Odoo via 123-SMS.net, service français d'envoi de SMS professionnels depuis 2002. Crédits prépayés sans abonnement ni date d'expiration.

Fonctionnalités

  • Assistant d'envoi depuis les contacts (Action > Envoyer un SMS, numéro prérempli) ;
  • API réutilisable dans vos actions automatisées et crons : self.env['sms123.api'].envoyer(numero, message) ;
  • Réglages intégrés (identifiant, clé API, sender-ID personnalisé) ;
  • Normalisation des numéros français, codes retour tracés dans le journal.

Mise en route (2 minutes)

  1. Inscription gratuite sur 123-sms.net (5 SMS offerts) ;
  2. Configuration > Paramètres généraux > 123-SMS : identifiant + clé API (transmis à l'inscription) ;
  3. Fiche contact > Action > Envoyer un SMS (123-SMS) : testez !
